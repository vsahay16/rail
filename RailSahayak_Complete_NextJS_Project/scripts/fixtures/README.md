# RailKit response fixtures

The railkit-*.json examples were extracted from RailKit's public documentation on 31 October 2026. They are illustrative fixtures, not live service results. Never serve these files as production data.

Sources: https://railkit.in/docs/live-tracking, /live-tracking-v2, /station-timetable, /station-amenities, /cancelled-trains, /train-history, /train-name-search, /train-by-number.

seat-availability.json is the verified example supplied by the project owner. Its dates and percentages are for tests only.
